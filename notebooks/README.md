# Notebooks

For exploring data and drafting charts. We use plain `.py` files split into cells with `# %%`, so they open in Spyder (run one cell with Ctrl+Enter) and in VS Code. Name them `<number>_<initials>_<topic>.py`, for example `01_dh_pick_vs_odds.py`.

When the code in a notebook works, move it into the `pvb` package so everyone can run it.
